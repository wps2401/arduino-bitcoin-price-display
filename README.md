# arduino-bitcoin-price-display

## Description
Uses an Arduino Uno R4 WIFI to query an API for the current Bitcoin price and display it on an LCD.

## Components
1x Arduino Uno R4 WIFI  
1x 16x2 LCD Display in 4 bit mode  
1x Potentiometer  
1x Breadboard  

## Pins
| LCD Pin | Label | Wire To         |  
| ------- | ----- | --------------- |  
| 1       | VSS   | GND             |  
| 2       | VDD   | 5V              |  
| 3       | VO    | Pot middle pin  |  
| 4       | RS    | D12             |  
| 5       | RW    | GND             |  
| 6       | E     | D11             |  
| 7       | D0    | —               |  
| 8       | D1    | —               |  
| 9       | D2    | —               |  
| 10      | D3    | —               |  
| 11      | D4    | Arduino D5      |  
| 12      | D5    | Arduino D4      |  
| 13      | D6    | Arduino D3      |  
| 14      | D7    | Arduino D2      |  
| 15      | LED+  | 5V              |  
| 16      | LED−  | GND             |
